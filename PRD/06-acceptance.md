# 验收

每条都是可演示、可失败的。做不到「设置页能开但手机连不上」那种半成品。

## 配对与身份

1. 扫一份 Companion 邀请，先进文件夹，无需先贴 token。
2. 无效码显示「这不是 VibeX 邀请」。
3. 过期或 scope 超出 Companion：一句原因 + 「请在电脑上再出示邀请」。
4. 手填 origin + 8 位码可以完成配对。
5. 粘贴管理员 token 或 `vbx_device_` 被拒绝。
6. 已配对后再出示同一 Host 邀请：地址更新，不出现第二个档案。文案「已更新地址」。
7. 邀请中的 `127.0.0.1` 被忽略。

## 连接

8. 信号条在 connecting / online / recovering / offline / auth_required / incompatible 下与文案表一致。
9. 非 online 时发送、纠偏、审批、新建均不可用，且原因可见。
10. 关 Host：列表只读，时间线不丢，发送不可用。
11. 再开 Host：用 `after_sequence` 续上，不丢、不双份气泡。
12. 协议不兼容进入 `incompatible`，禁止写。
13. 撤销设备后 WS 断开，状态 `auth_required`。

## 会话闭环

14. 选项目后看到近 3 天会话；可改为 7 / 30。
15. 新建会话：选项目、工作区、就绪 Agent，提交后打开时间线。
16. 发送一条跟进，时间线出现用户气泡，随后助手输出按 delta 合并。
17. 在途时可取消这一轮。
18. 在途且能力允许时可纠偏；不支持时失败，不变成排队。
19. 已有在途时再发送进入队列；可取消未认领输入。
20. 待办能批掉一张权限，桌面同一请求消失。
21. 提问能在卡片内作答。
22. 中断 Turn 显示须手点重试，没有自动重发。
23. 未知事件显示「Host 更新了此会话」，应用不崩。
24. 缺失用量不显示 0。

## 范围

25. 没有入口能改 MCP、Git 远程、监听、插件、Workflow / Automation。
26. 终端只有只读摘要，没有 PTY 键盘。
27. 文件变更不能提交或推送。

## 离线与监控

28. 断网后打开已缓存会话可读。
29. 离线输入框不可提交，没有「稍后发送」。
30. 持续监控默认关；打开后终态可成本地通知，通知不含 prompt / 路径。

## 平台

31. 凭证在 Keychain；备份与日志不含凭证。
32. 拒绝相机仍可手动配对。
33. Dynamic Type 放大后列表与 Composer 仍可用。
34. Reduce Motion 下没有呼吸动画与行长出。
35. iPhone 四栏可走完配对 → 文件夹 → 会话 → 时间线 → 审批。
36. iPad 分栏可在不丢失时间线的情况下切换会话。

## 设计

37. 屏幕使用 [`impeccable/`](../impeccable/README.md) 的 Theme / Glass / 状态视图，而不是 Material 移植或 Web 卡片堆。
38. 底栏仍是文件夹 / 会话 / 状态 / 设置，没有第五个搜索 Tab，没有 Git / MCP 设置页。
