# 功能需求

信息架构对齐 Android Companion，**不是** codeg-ios 的五栏（会话 / 项目 / 活动 / 搜索 / 设置）。底栏四处：**文件夹 / 会话 / 状态 / 设置**。连接 Host 后先落在文件夹。

视觉与组件实现见 [`impeccable/`](../impeccable/README.md)。

## 1. 开屏

冷启动：`Theme.bg` + 标记，约 0.8 秒。系统关闭动画则瞬切。不开功能介绍、不写卖点列表。

已有 Server Profile：开屏结束后进入连接流程，落到文件夹。
没有档案：进入未配对屏。

## 2. 未配对

一屏：标记、短句「连接到你的 VibeX」、一句「打开电脑桌面端 → 设置 → 远程连接，点击「生成连接码」」、主按钮「扫描连接二维码」、次按钮「手动输入连接码」。

不要功能卖点。不要在图标下再写 VibeX。

### 2.1 扫描

扫描 `vibex-pairing:`。无效码：「这不是 VibeX 邀请」。相机权限只在进入扫描时请求；拒绝则走手动，不反复弹。

### 2.2 手动

origin + pairing token（8 位连接码，或完整邀请原文）。无「管理员 token」栏。粘贴 `vbx_device_` 或管理员口令：「不要粘贴管理员或设备长期口令，请使用电脑上的邀请」。

### 2.3 兑换结果

| 情况 | 行为 |
| --- | --- |
| 未配对、secret 有效 | 向可及 origin 兑换，按 Host 身份建档案，进入文件夹 |
| 未配对、secret 过期 / scope 超出 Companion | 一句原因 + 「请在电脑上再出示邀请」 |
| 已持有该 Host 身份 | 合并 Reachability，成功文案「已更新地址」，不当新档案 |
| 全部 origin 失败 | 列出尝试结果，主按钮「再扫描邀请」，次按钮「打开 Host」（若可） |

兑换中显示进行态，禁止连点产生两次兑换。

## 3. 连接与信号条

顶栏始终说出 Host 名和连接态，不用 toast 当主状态。

| 状态 | 信号条 | 写 |
| --- | --- | --- |
| connecting | 正在连接 | 禁 |
| online | 在线 · {档案名} | 允许 |
| recovering | 正在恢复 | 禁 |
| offline | 离线 · 上次同步 {相对时间} | 禁 |
| auth_required | 需要重新配对 | 禁 |
| incompatible | 版本不兼容 | 禁 |

试探顺序：上次成功 origin → 远程 HTTPS → 其余。`127.0.0.1` / `localhost` 永不进入试探列表。Host 在线时刷新 Reachability 名单。

旋转、进程被杀、网络切换：档案与 sequence checkpoint 仍在，重连用已确认的最大 sequence 作为 `after_sequence`。

## 4. 文件夹

连接后的第一屏。列出 Host 历史项目：名称、目录路径、是否已选。点选后记住该项目，并同步近 3 天会话。

- 顶：搜索项目名或路径。
- 行：色点 + 名称 + 路径末段；已选有标记。
- 长按 / 上下文菜单：查看信息、在此项目新建会话。
- 下拉刷新目录。
- 空：Host 上还没有项目。失败：一句原因 + 「重试」。

无 Git 写、无克隆仓库、无提交 / 推送。

## 5. 会话列表

标题是当前项目名，可切换项目。默认窗口「近 3 天」，可改为 7 / 30 天。

- 行：Agent 头像 + 状态点、标题、Agent · 四态、相对时间。
- 分组：置顶；其余按今天 / 昨天 / 本周 / 更早。
- 顶：搜索标题或 Agent。
- 右下「新会话」（仅 `online` 可点）。
- 待办条：若有未处理权限 / 提问，「N 条待你处理」，点进对应会话。
- 滑动 / 上下文菜单：置顶或取消置顶、重命名、归档、删除（写操作仅 `online`）。
- 未选项目：「先选择文件夹」。
- 空：`online` 则主按钮「新会话」；`offline` 则「上次同步 · 只读」。

## 6. 新会话

Sheet。只读目录来自 `conversation_catalog`（见协议文档 §目录）：

- Project（预选当前项目）
- Workspace：已有工作区，或「新建工作区」（名称 + 可选分支）
- 无工作区：仅当 Host 允许，单独一项
- 就绪且 usable 的 Agent（未就绪的标明原因，不可选）
- 可选初始 Prompt
- 创建时可选的 session mode / config（Host 给出的选项；缺失不填默认假装已应用）

提交走 `conversation_create` + 客户端 `operation_id`。失败留在 sheet 内，不关闭。成功打开时间线。

## 7. 时间线

全屏，底栏隐藏。系统边缘返回手势保持有效。

### 7.1 行种类

用户气泡、助手正文（Markdown）、折叠思考、工具卡、计划、子会话卡、队列 / 纠偏条、权限卡、提问卡、文件变更摘要、Artifact、终端摘要、恢复 / 错误条、未知事件占位。

时间线每行左侧一条细轨，颜色随行：在途用 accent、待办用 warning、终态用 tertiary、失败用 danger。

### 7.2 交互

- 权限 / 提问：卡片内直接批、拒、作答；同时进入待办汇总。
- Composer：跟进。在途且 Host 声明支持 steer 则纠偏，否则排队。取消只对在途 Turn。纠偏必须带 `expected_turn_id`；不支持时报错，不得改成排队。
- Composer token：`/` Skill 与命令、`@` 文件（工作区条目）、`#` 指令、`&` Agent 提及、`$`。候选项来自 Host；无则空，不本地编造。
- 只读：文件变更摘要、Artifact、终端摘要。可点开 diff / 内容，没有提交 / 推送 / PTY。
- 中断 Turn：说明须手点重试（新 Turn）；不自动重发。
- 未知事件：一行「Host 更新了此会话」，payload 进只读缓存。
- 用量、计划 status/priority、标题：只显示 Host / Agent 给出的字段。缺失保持缺失，禁止填 0，禁止从自由文本猜状态（ADR-0058）。
- 流式中：用户在底部附近才自动跟随；上翻时右下「新消息」pill，点回底部。
- 会话信息 sheet：项目 / 路径 / Agent / 当前 mode / 用量（有则显示）。可改 session mode 与 config option（`online`）。

### 7.3 Composer 与队列

`submit` 总是先持久化。空闲则立即成为 Turn；已有在途则排队。未认领输入可改可删；已认领不可编辑。同一 `operation_id` 重试不得产生第二条输入。

P1 不做跨设备草稿同步。未提交的输入框内容仅本机，杀进程可丢。

## 8. 状态

四态与桌面 Kanban 一致：待开始 / 进行中 / 待检查 / 已完成（wire：`todo` / `inprogress` / `inreview` / `done`）。

竖向四栏，每栏可折叠，栏内是会话卡片（标题、相对时间、分支）。未选项目：「先选择文件夹」。点卡片打开时间线。`online` 时可改会话四态。

这不是 codeg-ios 的「待审批 / 正在运行 / 最近」活动页。待审批出现在时间线卡 + 会话列表待办条；状态页按 Kanban 看项目进度。

## 9. 设置

首页第一项是连接。顺序固定：

1. **连接** — Host 档案列表与切换、同步窗口（3 / 7 / 30 天）、持续监控开关、清除缓存、扫描以更新地址、忘记这台 Host
2. **外观** — 浅色 / 深色 / 跟随系统；强调色色板（默认 Neutral）
3. **消息流控制** — 思考（全部 / 折叠 / 隐藏，默认隐藏）、失败工具（默认不显示）、工具组件折叠、消息折叠
4. **Host** — 版本、协议、当前 origin、Host 身份（只读）
5. **能力** — 这台设备可用的 Host 能力（只读，fail-closed 的解释）
6. **关于** — VibeX Companion、版本

**没有** Agent 安装、MCP、Chat 通道、Git 账号、监听端口、专家、Skills 编辑、模型供应商。那些属于本机控制台或 Workstation。

忘记 Host：确认框。文案说清会删除本机档案与凭证，并在可达时撤销本设备。断开 ≠ 忘记。

## 10. 持续监控

默认关。用户在连接设置里显式打开。

打开后：应用可用后台任务 / 前台持续保持与 Host 的连接（iOS 用 BGTask / 明确的后台模式，不假装常驻），轮询或订阅终态摘要，发出**本地通知**。通知只含会话标题级信息与终态，不含 prompt、输出、路径。

P1 不接 APNs，不接 FCM。关掉监控即停止后台尝试。

## 11. 多档案

允许保存多个 Server Profile。同一 `host_id` 必须合并。切换档案断开当前连接，加载该档案的项目选择与离线缓存。同一时刻只连一台 Host。

## 12. 文案规则

- 按钮说结果：「允许」「拒绝」「发送」「取消这一轮」「忘记这台 Host」。
- 错误说原因和下一步，不道歉。
- 中英随系统语言；专有名 VibeX、Host、Agent 不译。
- 中英字符串进 String Catalog。
