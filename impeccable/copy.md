产品文案。用户词：邀请、配对、在线、待办、忘记。专有名 VibeX、Host、Agent 不译。按钮说结果。错误说原因和下一步，不道歉。

## 连接态

| 状态 | 信号条 |
| --- | --- |
| connecting | 正在连接 |
| online | 在线 · {档案名} |
| recovering | 正在恢复 |
| offline | 离线 · 上次同步 {相对时间} |
| auth_required | 需要重新配对 |
| incompatible | 版本不兼容 |

全部 origin 失败：列出尝试结果。主按钮「再扫描邀请」。

## 配对

- 标题：连接到你的 VibeX
- 说明：打开电脑桌面端 → 设置 → 远程连接，点击「生成连接码」。
- 主按钮：扫描连接二维码
- 次按钮：手动输入连接码
- 扫描提示：将连接二维码放入框内
- 无效：这不是 VibeX 邀请
- 缺码：需要连接码
- 口令误贴：不要粘贴管理员或设备长期口令，请使用电脑上的邀请
- 已有档案：已更新地址
- 过期 / 超出：请在电脑上再出示邀请

## 操作

允许。拒绝。发送。取消这一轮。忘记这台 Host。开始。再试一次。去选择。新会话。

忘记确认必须说清：删除本机档案与凭证，并在 Host 可达时撤销这台设备。断开不是忘记。

## 时间线

- 未知事件：Host 更新了此会话
- 中断：已中断。在电脑上检查工作区后再手点重试。
- 排队：已排队
- 纠偏不支持：当前 Agent 不能纠偏这一轮（不要改成已排队）
- 配置未生效：默认设置没有应用到这次会话
- 子会话：子会话（可点开）
